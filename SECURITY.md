# Security policy

## Supported versions

Security fixes are released on the latest published version of `pairjudge`.

## Reporting a vulnerability

Please use the repository's private security advisory form:

https://github.com/DaoyuanLi2816/pairjudge/security/advisories/new

Include a minimal reproduction, the affected version, and the expected impact.
Please do not open a public issue for an unpatched vulnerability.
